# ShikhaArti Graphics – Premium 3D Agency Website

A production-ready Next.js + Tailwind + React Three Fiber website with premium white/orange visual language, smooth motion, and modular sections.

## Stack
- Next.js (App Router)
- React
- Tailwind CSS
- React Three Fiber / Drei / Postprocessing
- GSAP + ScrollTrigger
- Framer Motion

## Run
```bash
npm install
npm run dev
```

## Notes
- Hero 3D canvas is lazy loaded using dynamic import and fallback skeleton.
- Scene uses environment lighting and subtle bloom for realism while staying minimal.
- Sections animate with fade-up scroll reveals and timeline progress animation.
