# Visual Inspiration Direction (ShikhaArti Graphics)

This document captures the visual direction used for the website build.

## Reference style pillars

- **Awwwards 3D agency websites**: clean hero-first composition, atmospheric depth, and restrained but premium interactivity.
- **Spline-inspired interactions**: smooth, soft-surface objects with subtle mouse-responsive parallax.
- **Three.js creative portfolios**: scene-led storytelling without heavy dark themes.
- **Stripe-like motion quality**: precise, eased transitions and tasteful glow accents.
- **Apple-like layout language**: high whitespace usage, light backgrounds, minimal typography hierarchy, and polished spacing rhythm.

## Applied design language

- **Background**: pure white `#ffffff`
- **Alternating section tone**: soft gray `#f5f7fa`
- **Accent gradient**: `#ff6a00 → #ff8c42 → #ffb347`
- **Mood**: elegant, minimal, professional, premium, and approachable (no cyberpunk styling)

## 3D object art direction

- Fluid abstract centerpiece using a smooth torus-knot form to emulate blob-like premium geometry.
- Soft matte + glass-hybrid transmission material.
- Warm orange key highlights with neutral fill lights.
- Gentle float and slow rotation; subtle pointer-follow parallax.
- Grounding shadow + studio environment reflections + restrained bloom.

## Motion behavior rules

- Scroll reveals with soft vertical fade-up.
- Timeline progress animation on entering viewport.
- No abrupt transitions; only eased, low-amplitude motion.
- Maintain compositional calm suitable for premium agency branding.
